# Controls and events

## Pause, resume, skip, reset

<Example files={[{ name: 'Controls.tsx', source: ControlsSource }]}>
  <Controls />
</Example>

| Method     | What it does                                                                       |
| ---------- | ---------------------------------------------------------------------------------- |
| `pause()`  | Freezes the animation and keeps the remaining delay.                               |
| `resume()` | Continues after `pause()`.                                                         |
| `skip()`   | Runs the remaining steps instantly, pauses included, and ends without looping.     |
| `stop()`   | Halts and keeps the text. `start()` continues with the next step.                  |
| `reset()`  | Clears the text, the queue and the listeners. It returns the typewriter, so you can chain new steps. |

`state.status` is one of `idle`, `typing`, `deleting`, `waiting`, `paused` and `done`.

## Events and promises

<Example files={[{ name: 'Events.tsx', source: EventsSource }]}>
  <Events />
</Example>

`on('start' | 'end' | 'loop', fn)` adds a listener and `off(event, fn)` removes it, `call(fn)` runs
a function at a point in the queue, and `start()` returns a promise that resolves when the queue
ends, stops or resets.
