# Speed

## Typing speed and humanize

<Example files={[{ name: 'Speeds.tsx', source: SpeedsSource }]}>
  <Speeds />
</Example>

`typeSpeed` and `deleteSpeed` are milliseconds per character (30 by default). `humanize` varies each
typing and deleting delay at random, from `0` (even) to `1` (anywhere between 0 and twice the
speed), which reads more like a person typing. Pauses stay exact.

These options can change while the animation runs; the next character uses the new value.

## Per-step speed

<Example files={[{ name: 'StepSpeed.tsx', source: StepSpeedSource }]}>
  <StepSpeed />
</Example>

Every typing and deleting step takes `{ speed }`. A speed of `0` is instant, which is how you print
output at once, as in the [terminal](../showcase/terminal.mdx).

:::note Very fast speeds
Below about 16 ms per character, the typewriter writes several characters per step instead of
scheduling faster timers, so it never renders more than about once per frame.
:::
