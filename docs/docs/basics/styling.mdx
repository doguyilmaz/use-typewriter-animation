# Colors and cursor

## Colors and highlights

<Example files={[{ name: 'Colors.tsx', source: ColorsSource }]}>
  <Colors />
</Example>

- `colorize(color)` sets the color of the text typed after it. `colorize()` goes back to the
  inherited color.
- `highlight(start, length, style)` styles a range of the text already on screen.
- `highlightWords(count, 'start' | 'end', style)` styles the first or last words.

Each run of equally styled text becomes one `<span>`; plain text stays a plain text node.

## Cursor

<Example files={[{ name: 'Cursors.tsx', source: CursorsSource }]}>
  <Cursors />
</Example>

The cursor is a `<span class="uta-cursor" aria-hidden="true">`. It stays solid while characters are
typed or deleted, blinks otherwise, and stops blinking when the user prefers reduced motion. It takes
the text color unless you set `cursorColor`. Style it like any element:

```css
.uta-cursor {
  margin-left: 1px;
  font-weight: 300;
}
```
