# Getting started

`use-typewriter-animation` types, deletes and styles text one character at a time. It ships a
component for the common cases, a hook for full control and the engine behind them, in about 2.8 kB
gzipped.

## Install

<Tabs groupId='package-manager'>

```bash
npm install use-typewriter-animation
```

  </TabItem>

It needs React 18 or 19 and has no other dependencies.

## The component

Pass a `sequence` to `<Typewriter>`. Strings are typed, numbers are pauses in milliseconds, and
functions are called when they are reached.

<Example files={[{ name: 'Loop.tsx', source: LoopSource }]}>
  <Loop />
</Example>

Each string replaces the text on screen with [`typeTo`](./api.md#queue-methods): only the part that
differs is deleted and retyped, so `I like ` stays put. A loop that runs longer than five seconds needs a
pause button; see [Accessibility](./guides/accessibility.md#let-people-pause-long-animations).

## The hook

`useTypewriter` returns a `typewriter` to queue steps on, plus the typed `elements` and the
`cursor` to render. Queue the steps in an effect and call `start()`.

<Example files={[{ name: 'Chain.tsx', source: ChainSource }]}>
  <Chain />
</Example>

`typewriter` is the same object for the life of the component, and the hook resets it on unmount, so
StrictMode does not type the text twice. An effect that runs once needs no cleanup; one that re-runs
when a value changes should clean up, as in
[Retype when a value changes](./basics/patterns.mdx#retype-when-a-value-changes).

## Which one should I use?

| Use                | When                                                                         |
| ------------------ | ---------------------------------------------------------------------------- |
| `<Typewriter>`     | The text is known up front: headlines, rotating words, taglines.            |
| `useTypewriter`    | You react to events, stream text, render the text yourself or need controls. |
| `createTypewriter` | You are not in a React component.                                            |

The component that calls `useTypewriter` re-renders once per typed character. Call it from a small
component, or use `<Typewriter>`, which keeps those renders to itself.
