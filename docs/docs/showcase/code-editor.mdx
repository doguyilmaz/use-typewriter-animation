## How it works

- `tokenize` splits the snippet into strings, keywords, tags and so on. Each token is queued with
  `colorize(color).type(text)`; consecutive tokens of the same color share a `<span>`.
- A line break and its indentation are one token typed at `{ speed: 0 }`, like an editor that
  indents for you.
- The gutter and the status bar are derived from `state.text` on every render.
