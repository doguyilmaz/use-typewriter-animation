## How it works

- The rotating part is a `<Typewriter>` inside the heading, so the heading text never moves.
- Every role is reached with `typeTo`, which deletes only what differs.
- The gradient uses `background-clip: text`. The cursor gets its own `cursorColor`, because the
  text color is transparent.
- Screen readers get the full sentence from a visually hidden span, and the animation is
  `aria-hidden`. See [Accessibility](../guides/accessibility.md).
- Colors use `light-dark()`, which follows the page's `color-scheme`. If your dark mode toggles a
  class, set `color-scheme: dark` with it.
