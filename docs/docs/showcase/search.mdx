# Search placeholder

Suggestions typed into a search field placeholder. Click the field: the animation pauses until it loses focus.

## How it works

- The hook's `sequence` option plays the suggestions without an effect, and `enableCursor: false`
  drops the cursor because the text goes into the `placeholder` attribute through `state.text`.
- `typeTo` keeps `Search for “` on screen and retypes only the suggestion.
- Focusing the field calls `pause()`, so nothing is scheduled or rendered while the user types, and
  blurring it calls `resume()`.
- Placeholder changes are not announced by screen readers, so the field keeps a fixed `aria-label`.
- Colors use `light-dark()`, which follows the page's `color-scheme`. If your dark mode toggles a
  class, set `color-scheme: dark` with it.
