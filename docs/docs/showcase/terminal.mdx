## How it works

- `humanize: 0.6` makes the typing uneven, and `cursorStyle: 'block'` draws a terminal cursor.
- `{ speed: 0 }` prints prompts and output instantly, with short `pauseFor` gaps between lines.
- The `run` helper is plain code that queues steps; build scripts out of functions like it.
- The text sits in a `<pre>`, and line breaks render as `<br>`.
